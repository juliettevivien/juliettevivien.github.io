About me:

I have a background in biology and specifically neurosciences. After a preclinical project studying the fascinating chandelier cells in mice, I started a PhD in clinical neurosciences to get more familiar with the medical domain, medical devices and signal processing.

Along my PhD journey, I have faced challenges in multimodal data synchronization and data preprocessing when confronted to new data types without existing tools to handle them. This motivated me to develop my first python-based toolbox with a graphical user interface for data synchronization (link to the preprint in my Publications section). This project combines signal processing and user interface design and was a lot of fun to develop!
